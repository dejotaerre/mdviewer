# Leer con calma

Bienvenido a **mdviewer**, tu visor de Markdown para GNOME. Un espacio sencillo para leer apuntes, documentación e ideas.

## Lo importante, a la vista

Los títulos organizan el contenido, las **negritas** destacan lo esencial y las *cursivas* aportan matices. También puedes leer `código en línea` sin perder el hilo.

> Un buen documento deja respirar a las ideas.

## A tu ritmo

| Acción | Atajo |
| :--- | :--- |
| Abrir un archivo | Ctrl + O |
| Buscar en el documento | Ctrl + F |
| Aumentar o reducir el texto | Ctrl + + / Ctrl + − |
| Recuperar el tamaño original | Ctrl + 0 |
| Volver a cargar el archivo | Ctrl + R |

También puedes **arrastrar un archivo** sobre la ventana, o elegir **mdviewer** desde «Abrir con» en Archivos.

## Código fácil de leer

```python
def saludar(nombre):
    return f"Hola, {nombre}. ¡Que disfrutes la lectura!"

print(saludar("Héctor"))
```

- El aspecto claro u oscuro sigue la preferencia de GNOME.
- Las imágenes locales se muestran junto al texto.
- Los enlaces web se abren en tu navegador.
- Los archivos originales se conservan: este visor es de **solo lectura**.
